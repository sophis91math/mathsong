# 수학송 가사 스튜디오 — 설정 안내서

중3 학생이 단원을 골라 가사를 쓰고, Suno로 노래를 만든 뒤 가사를 제출하면 선생님이 한곳에서 모아 보는 웹앱입니다.
학생은 **로그인 없이** 사용하고, 선생님만 **구글 계정으로 로그인**해서 제출물을 봅니다.

## 파일 구성

| 파일 | 하는 일 | 고칠 일 |
|---|---|---|
| `index.html`, `app.js` | 학생 화면 (6단계) | 없음 |
| `teacher.html`, `teacher.js` | 선생님 모아보기 화면 | 없음 |
| `data.js` | 단원 7개 핵심 개념, Suno 스타일 예시 10개 | 내용을 바꾸고 싶을 때만 |
| `style.css` | 디자인 | 없음 |
| `firebase-config.js` | Firebase 연결 값, 선생님 이메일 | **꼭 고치기 (3단계)** |
| `firestore.rules` | 데이터 보안 규칙 | **이메일 한 곳 고치기 (4단계)** |

---

## 1단계. Firebase 프로젝트 만들기 (약 5분)

1. https://console.firebase.google.com 에 선생님 구글 계정으로 들어갑니다.
2. **프로젝트 추가** → 이름 예: `mathsong` → Google 애널리틱스는 꺼도 됩니다 → 만들기.

## 2단계. 데이터베이스와 로그인 켜기

1. 왼쪽 메뉴 **빌드 → Firestore Database → 데이터베이스 만들기**
   - 위치: `asia-northeast3 (서울)` 
   - **프로덕션 모드**로 시작 (규칙은 4단계에서 넣습니다)
2. 왼쪽 메뉴 **빌드 → Authentication → 시작하기 → 로그인 방법 → Google → 사용 설정 → 저장**

## 3단계. 웹 앱 등록하고 설정 값 복사하기

1. 프로젝트 개요 옆 ⚙️ **프로젝트 설정** → 아래 **내 앱**에서 `</>`(웹) 아이콘 클릭
2. 앱 별명 예: `mathsong-web` → 앱 등록 (Firebase 호스팅은 체크하지 않아도 됩니다)
3. 화면에 나오는 `const firebaseConfig = { ... }` 안의 값 6줄을 복사해
   `firebase-config.js`의 같은 이름 자리에 붙여넣습니다.
4. 같은 파일 맨 아래 `TEACHER_EMAIL`에 선생님 구글 계정 이메일을 적습니다.

> apiKey 같은 값은 웹페이지에 공개되어도 괜찮게 만들어진 값입니다. 실제 보호는 4단계의 규칙이 합니다.

## 4단계. 보안 규칙 넣기

1. **Firestore Database → 규칙** 탭
2. 있던 내용을 지우고 `firestore.rules` 파일 내용을 통째로 붙여넣습니다.
3. 그 안의 `TEACHER@gmail.com` 을 선생님 구글 이메일로 바꿉니다. (3단계와 같은 이메일)
4. **게시** 클릭

이 규칙으로:
- 학생은 가사를 **새로 제출만** 할 수 있고, 다른 친구 가사를 보거나 고치거나 지울 수 없습니다.
- 선생님 계정만 전체를 보고 지울 수 있습니다.
- 너무 긴 글이나 이상한 항목이 들어오면 저장을 거절합니다.

## 5단계. GitHub에 올리기 (GitHub Pages)

1. https://github.com 에서 **New repository** → 이름 예: `mathsong` → **Public** → Create
2. 저장소 화면의 **uploading an existing file** (또는 Add file → Upload files)을 눌러
   이 폴더의 파일 전부를 끌어다 놓고 **Commit changes**
3. 저장소 **Settings → Pages** → Source: `Deploy from a branch`, Branch: `main` / `(root)` → Save
4. 1~2분 뒤 위쪽에 주소가 나옵니다: `https://<아이디>.github.io/mathsong/`
   - 학생용: `https://<아이디>.github.io/mathsong/`
   - 선생님용: `https://<아이디>.github.io/mathsong/teacher.html`

## 6단계. 로그인 허용 도메인 추가 (안 하면 선생님 로그인이 안 됩니다)

Firebase **Authentication → 설정 → 승인된 도메인 → 도메인 추가** → `<아이디>.github.io` 입력 → 추가

## 7단계. 수업 전 확인

1. 학생용 주소에서 이름, 단원, 가사를 아무렇게나 넣고 **가사 제출하기** → "제출했어요!"가 나오면 성공
2. 선생님용 주소에서 **구글로 로그인** → 방금 낸 가사가 보이면 성공 → 시험 제출은 **삭제**
3. 학생들에게는 학생용 주소만 알려 주세요. (QR코드로 만들어 칠판에 띄우면 편합니다)

## 알아 두면 좋은 점

- **다시 제출하면 새 건으로 쌓입니다.** 선생님 화면은 기본으로 같은 반·같은 이름의 *가장 최근 것만* 보여 줍니다. 체크를 끄면 전부 보입니다.
- 학생 화면은 쓰던 내용을 그 브라우저에 자동 저장합니다. 같은 컴퓨터를 여러 반이 쓴다면 제출 후 내용을 지우게 해 주세요.
- 무료 요금제(Spark)로 충분합니다. (하루 쓰기 2만 건, 읽기 5만 건)
- 학생 쪽은 로그인이 없어서, 주소를 아는 사람은 누구나 제출할 수는 있습니다. 수업이 끝나면 4단계 규칙에서 `allow create: if ...` 줄 앞부분을 `allow create: if false && ...` 로 바꿔 제출을 닫을 수 있습니다.
- Suno 사용 연령·약관(만 13세 이상 등)과 학교 정책은 수업 전에 확인해 주세요.
