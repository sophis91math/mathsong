# 수학송 가사 스튜디오 — 설정 안내서

중3 학생이 단원을 골라 가사를 쓰고, Suno로 노래를 만든 뒤 패들렛에 올리는 웹앱입니다.
학생은 로그인 없이 사용하고, 데이터베이스나 별도 서버가 필요 없습니다.

## 학생 화면 6단계

1. 우리 팀 정보 (반, 번호, 이름 1~2명)
2. 단원 고르기 (7개 단원, 핵심 개념과 후렴에 넣기 좋은 말 안내)
3. 노래 스타일 고르기 (Suno 스타일 예시 10가지, 영어 스타일 문장과 예시 가사)
4. 가사 쓰기 ([Verse]/[Chorus] 버튼, 체크 표시)
5. Suno에서 노래 만들기 (가사·스타일·제목 복사 버튼)
6. 완성한 노래를 패들렛에 올리기 (노래 링크 입력 → 제목, 가사·링크 복사 → 패들렛 열기)

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `index.html`, `app.js` | 학생 화면 |
| `data.js` | 단원 7개 핵심 개념, Suno 스타일 예시 10개 (내용을 바꾸고 싶을 때만 고치기) |
| `config.js` | 패들렛 주소 (다른 패들렛을 쓸 때만 고치기) |
| `style.css` | 디자인 |

## GitHub Pages에 올리기 (약 5분)

1. https://github.com 에 로그인 → 오른쪽 위 **+ → New repository**
2. 이름 예: `mathsong` → **Public** 선택 → **Create repository**
3. 저장소 화면에서 **uploading an existing file** (또는 Add file → Upload files)을 누르고,
   압축을 푼 `mathsong-web` 폴더 **안의 파일들**을 끌어다 놓기 → **Commit changes**
   (폴더째 올리지 말고 파일들만 올려야 주소가 간단해집니다)
4. 저장소 **Settings → Pages** → Source: `Deploy from a branch`, Branch: `main` / `(root)` → **Save**
5. 1~2분 뒤 같은 화면 위쪽에 주소가 나옵니다: `https://<아이디>.github.io/mathsong/`
6. 이 주소를 학생들에게 알려 주세요. (QR코드로 만들어 칠판에 띄우면 편합니다)

## 수업 전 확인

- 학생 화면에서 아무 단원과 가사, 노래 링크를 넣고 6단계 **제목 복사 → 패들렛 열기 → + → 붙여넣기**가 되는지 한 번 해 보세요.
- 패들렛 설정에서 로그인하지 않은 방문자도 글을 쓸 수 있는지 확인해 주세요.
- 학생 화면은 쓰던 내용을 그 브라우저에 자동 저장합니다. 컴퓨터실처럼 여러 반이 같은 컴퓨터를 쓰면 다 올린 뒤 내용을 지우게 해 주세요.
- Suno 사용 연령·약관(만 13세 이상 등)과 학교 정책은 수업 전에 확인해 주세요.

## 내용 고치기

GitHub 저장소에서 `data.js`나 `config.js`를 누르고 연필 아이콘(✏️)으로 고친 뒤 **Commit changes**를 누르면 1~2분 뒤 사이트에 반영됩니다.
